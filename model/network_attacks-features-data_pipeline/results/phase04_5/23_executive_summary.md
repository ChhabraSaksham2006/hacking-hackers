# 23 — Executive Summary

## 1. What Has Been Built?

The project implements a complete, mathematically rigorous network telemetry forecasting pipeline for SIH26153:
1. **Canonical Ingestion & State Representation:** 8.28 million flows from CSE-CIC-IDS2018 are converted into 188,520 consecutive 54-dimensional macro-behavioral telemetry state vectors $S_t$ over rolling 10-second windows with 2-second stride.
2. **Chronological OOD Split:** Days 1–5 for training (DoS, BruteForce, DDoS), Day 6 for validation (Web Attacks), and Days 7–9 for testing (unseen Infiltration and Botnet attacks).
3. **Comprehensive Baselines:** Majority class, Persistence, Logistic Regression, Random Forest, Temporal GRU, and Temporal Transformer evaluated across forecast horizons from $K=1$ (2.0s) to $K=300$ (600.0s / 10 minutes).
4. **World Model Architecture:** A Recurrent State Space Model (`SparseRSSM`) featuring an MLP encoder, 128-D latent state, Straight-Through Top-K magnitude gating, GRUCell temporal memory, and an autonomous recursive rollout transition model.

## 2. Core Forensic Discoveries

1. **The Untrained Attack Head in RSSM:**
   While the recursive continuous state rollout is mathematically functional and trained against future continuous state targets, `SparseRSSM.loss()` omits the attack classification head. The attack logits are generated by an untrained, randomly initialized linear layer. At threshold 0.5, this head predicts attacks on ~75% of test samples (an aggressive positive rule), yielding an artificially flat F1 (~0.554) with high recall (~99%) but excessive false positive rates (~64%–66%).
2. **The "Persistence Paradox":**
   In CSE-CIC-IDS2018, attack sessions are massive contiguous blocks (e.g., Botnet runs for 720 minutes; Infiltration runs for 535 minutes). Across the 3 test days, there are only 7 attack onsets versus 18,867 continuation positives. A naive persistence forecaster ($y_{t+K} = y_t$) achieves an F1 of 0.9996 at $K=1$ and 0.9186 at $K=300$ purely by exploiting episode continuation. On pure pre-onset transitions ($Y_t = 0, Y_{t+K} = 1$), persistence F1 collapses to exactly 0.0000.
3. **Random Forest Competitiveness:**
   When retrained directly per horizon, Random Forest achieves F1 of 0.6139 at $K=50$ (100s) and 0.5581 at $K=100$ (200s), outperforming linear models.

## 3. Executive Answers to Core Audit Inquiries

- **Does RSSM outperform Random Forest?** No; the current RSSM attack head is untrained.
- **Does RSSM outperform Persistence?** No; persistence achieves 0.9186–0.9996 on continuation-dominated test sets.
- **Does Sparse RSSM outperform Dense RSSM?** Top-50 achieves comparable state MSE (0.4006 vs 0.3607 at K=1); Top-10 suffers instability and diverged at K=100.
- **Does the model forecast attack ONSET?** Pre-onset evaluation has NOT been run on ML/RSSM models; verified only for Persistence (where it is 0.0000).
- **Does the model forecast continuous state?** Yes; Dense RSSM continuous rollout MSE scales from 0.3607 at $K=1$ to 0.6279 at $K=300$.
